Principles I work by

Ten years of building and operating production systems has left me with a short list of convictions: boring technology wins, observability is a feature, and the best abstraction is the one you didn't need. I write about these on the blog.

  • Design for the failure case first — the happy path takes care of itself
  • Small, reversible deployments beat big-bang releases
  • Documentation is part of the deliverable, not an afterthought
  • If it isn't monitored, it's already broken
